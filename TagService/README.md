# TagService - сервис для управления тегами на платформе

## Описание

Сервис запускается на порту **5341** и предоставляет REST API для:

-   Создания, обновления и удаления тегов
-   Управления счетчиком использования тегов
-   Получения тегов по списку идентификаторов
-   Поиска тегов с пагинацией

## Технические характеристики

-   **Архитектура**: Vertical Slice Architecture
-   **База данных**: PostgreSQL latest
-   **Язык**: C# (.NET 8)
-   **Аутентификация**: JWT через общий публичный ключ
-   **Логирование**: SEQ logging
