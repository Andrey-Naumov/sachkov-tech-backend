# Faq Service - сервис для управления пользовательскими аккаунтами на платформе.

## Описание

Сервис запускается на порту **8006**.

Этот репозиторий предоставляет собой сервис по работе с вопросам пользователей и ответами на них.

Поиск существующих вопросов основан на ElasticSerch, а хранение на PostgreSQL.
